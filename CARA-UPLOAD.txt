═══════════════════════════════════════════════════════════
LANGKAH 2 — Upload folder src (CARA TERMUDAH)
═══════════════════════════════════════════════════════════

1. Buka: https://github.com/diramadhansalsabil-cyber/SI-TAMU-RRI

2. Klik: Add file → Upload files

3. Buka folder di komputer:
   c:\xampp\htdocs\SI-TAMU RRI\GITHUB-UPLOAD

4. DRAG folder "src" ke halaman GitHub
   (GitHub akan replace file yang sudah ada)

5. Commit message: Fix hapus cetak dan jam WITA

6. Klik: Commit changes

ATAU extract FIX-UPLOAD.zip lalu drag folder src
