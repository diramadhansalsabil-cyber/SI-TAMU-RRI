BAGIAN F — JIKA SCRIPT GAGAL (alternatif manual Git)
═══════════════════════════════════════════════════════════════════

Langkah F1. Buka PowerShell atau CMD

Langkah F2. Jalankan perintah satu per satu:

  cd "c:\xampp\htdocs\SI-TAMU RRI"
  "C:\Program Files\Git\bin\git.exe" clone https://github.com/diramadhansalsabil-cyber/SI-TAMU-RRI.git %TEMP%\si-tamu-deploy
  xcopy /E /I /Y "src" "%TEMP%\si-tamu-deploy\src"
  copy /Y next.config.ts "%TEMP%\si-tamu-deploy\"
  cd %TEMP%\si-tamu-deploy
  "C:\Program Files\Git\bin\git.exe" add src/ next.config.ts
  "C:\Program Files\Git\bin\git.exe" commit -m "Fix: update src folder"
  "C:\Program Files\Git\bin\git.exe" push origin main

Langkah F3. Login dengan token saat diminta (sama seperti Bagian B4)

═══════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Masalah: "Push gagal" / "Authentication failed"
  → Token salah atau expired. Buat token baru (Bagian A).

Masalah: "Running scripts is disabled"
  → Pakai DEPLOY.bat (bukan klik kanan .ps1 langsung).

Masalah: Website masih lama setelah deploy Ready
  → Ctrl+Shift+R, atau buka tab Incognito/Private.

Masalah: Vercel build Error
  → Cek Environment Variables di Vercel (4 variabel wajib):
     NEXT_PUBLIC_SUPABASE_URL
     NEXT_PUBLIC_SUPABASE_ANON_KEY
     SUPABASE_SERVICE_ROLE_KEY
     NEXT_PUBLIC_APP_URL=https://si-tamu-rri-kdi.vercel.app

Masalah: Perubahan tidak muncul meski GitHub sudah benar
  → Pastikan file di path src/... bukan GITHUB-UPLOAD/src/...
